.NET Framework4.5 설치 과정(운영체제 Vista, Windows7, Windows10)

- .Net Framework 4.5 DownLoad -
  • 1. . NET Framework 4.5 링크를 클릭한 뒤 언어를 한국어로 선택한 수 다운로드 버튼 클릭
  • 2. '다음사항을 제안..' 창에서 '건너뛰고 다음 단계 진행' 클릭
  • 3. 실행 및 저장 단계에서 실행 버튼 클릭
  • 4. 사용약관 동의함에 체크표시한 후 설치 버튼 클릭
  • 5. 그러면 자동으로 설치가 진행됩니다.
  • 6. IntraLogis Deploy 과정 완료

'제어판'의 '프로그램 추가/제거'에서 Microsoft .NET Framework 4.5 설치여부 확인 설치가 안되어 있을 경우,
